| D54 | **Remote access, first slice: server mode + code pairing.** (1) The main process runs on a Linux VPS as a systemd *user* service (`ducter service install`: `Restart=on-failure`, journald, linger, data in `~/.ducter`), bound to 127.0.0.1 unless `--host` says otherwise. (2) Off-machine clients pair once: `ducter pair` shows a one-time 8-character code (10 min, single use, unambiguous alphabet) with the address, a pasteable link and a QR; `POST /pair` trades it for a long-lived **device token**. Codes and tokens are stored only as SHA-256 hashes; wrong codes are rate limited; each device is revocable (`ducter devices disconnect`). (3) A request is *local* only if the peer and the Host are loopback and no proxy header is present; local clients stay token-free, everything else needs the token on `/ws`, and on `/mcp` beside the role token. (4) TLS is never hand-rolled: Caddy with automatic HTTPS on the user's own domain (Q18, `scripts/caddy-setup.sh`); an SSH tunnel is the zero-domain fallback. (5) The desktop gets **连接到你的 Ducter / Connect to your Ducter** (address + 配对码), token in a 0600 file. (6) Workers dial out to `/worker`; the main places tasks on them by `Place.device` (state stays on the main; the worker holds the place and runs the harness), and a worker that drops mid-task makes its tasks 在等 · <device> 连不上 after 2 min and resumes them by session id. Refines D40 (this is its code half; the WebCrypto device key + passkey and the Edge relay of D39/D46 remain the phone/web target). *Proposed overnight from the user's ask; accepted 2026-11-09 morning (U "按建议"); the code is shown as 连接码 / Code since D65* | U (ask) + L, R29 | `design/system.md`, `roadmap.md`, `design/onboarding.md`, `design/product-model.md` §1, `design/scenarios.md` |
| D55 | **Ducter.app is signed with the Nowledge Labs Developer ID and notarized**, the way con and Nowledge Mem ship. Bundle id `co.nowledge.ducter` (helper `co.nowledge.ducter.cli`), following `co.nowledge.con` and `co.nowledge.mem.desktop` (reverse DNS of nowledge.co); replaces the ad-hoc id `dev.ducter.app`. Hardened runtime on the app and helper; the helper's only entitlement is `com.apple.security.cs.allow-jit` (Bun's JIT dies without it, tested).
