# Ducter docs

Ducter is a personal AI you run yourself. You talk to one partner, in one conversation. It hands
the real work to Claude Code or Codex on your own computers, using the AI plan you already pay
for, and comes back when the work is done, with how it checked. It asks for you only when a
decision is truly yours.

These pages are for using Ducter. If you want to build it or change it, start with the
[README](../README.md) and [CONTRIBUTING](../CONTRIBUTING.md) in the repository instead.

> **Ducter is an early preview.** It works end to end on a Mac and on a Linux server, and it
> still has rough edges. Where something isn't built yet, these pages say "coming soon".

## Words you'll see

| You'll see | What it means |
|---|---|
| **Partner** | The one you talk to. It's called Ducter until you give it another name. |
| **Task** | Something big enough that your partner hands it off to work on by itself. Each one gets a card. |
| **On hand** | Every task at a glance, and what is waiting for you. |
| **Needs you** | A task or question that is waiting for your decision. |
| **Go · Hold · Reply…** | Your answers to a decision. Go takes the suggested default, Hold says "not yet", Reply lets you say it in your own words. |
| **How I know** | The proof under a finished result: tests that ran, checks, the changes. |
| **Devices** | The computers (and phone) Ducter can use: **Awake**, **Asleep**, or **Can't reach**. |
| **Stop Ducter · Wake** | The one way to stop everything, and the way to start it again. |
