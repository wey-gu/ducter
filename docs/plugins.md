# Plugins

A plugin adds something to Ducter that someone else made: a **look** (colours, corners and feel),
a **page** in Ducter, or a **source** of your past work. Each one can only do what its card says
when you install it, and only you install it.

Today Ducter reads one kind: a **look**. (Pages and sources come later; these pages say so where
they aren't built yet.)

## A look

A look changes how Ducter looks — its colours, corners and feel — for both the light and the dark
paper, on your phone and your Mac. It is only data: it has no code, it reads nothing of yours, it
never goes online, and it never changes how a page is laid out.

To install one:

1. Run `ducter plugin add <folder-or-address>`.
2. Open **Settings › Plugins** (or **Settings › Look and sound**). The look's row shows a small
   preview of its colours and a card that says, in plain words, what it changes. It reads nothing.
3. Tap **Install**. The whole app is now that look, on every device.
4. **Back to Pebble** is always one tap away, and keeps the look installed for when you want it
   again.

A look from Ducter's own list says **Ducter checked this version**; anything else says **Nobody has
checked it for you**.

## What a plugin can never do

A look can't read your files, run a program, go online, or change a page's layout. Pages and
sources, when they come, will show their own limits on the same card before you install them.
