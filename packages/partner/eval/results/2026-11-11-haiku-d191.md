  [partner message] 直接把文件路径跟在后面就行：

```bash

```

如果只记得文件名的一部分，也可以写个关键字，bun 会匹配路径里包含它的测试文件：

```bash
bun test foo
```

bun test test/foo.test.ts -t "某个用例名"
