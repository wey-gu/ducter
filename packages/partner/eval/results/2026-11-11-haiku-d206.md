  [partner message] 用路径直接指定文件就行：

```
bun test test/foo.test.ts
```

如果不想写全路径，也可以只给文件名的一部分，bun 会跑所有路径里包含这段字符串的测试文件：

```
bun test foo
```

想只跑某个测试用例（而不是整个文件），加 `-t`：

```
bun test test/foo.test.ts -t "某个用例的名字"
```
