  [partner message] `bun test` 后面直接跟文件路径就行：

```bash
bun test src/utils/parse.test.ts
```

也可以只写文件名的一部分，Bun 会匹配路径里包含这段字符的测试文件：

```bash
bun test parse
```

要只跑某个测试用例，用 `-t`（或 `--test-name-pattern`）按名字过滤：

```bash
bun test parse.test.ts -t "空字符串"
```
