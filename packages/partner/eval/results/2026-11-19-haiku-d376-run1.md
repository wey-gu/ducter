### direct-zh-howto

```
--- step 1: user says: bun test 怎么只跑一个测试文件？
  [partner message] 用文件路径直接指定就行：

```sh
bun test test/user.test.ts
```

如果不想写全路径，也可以只给文件名的一部分，Bun 会跑路径里包含这段字符串的测试文件：

```sh
bun test user
```

想只跑某一个测试用例，用 `-t`（或 `--test-name-pattern`）按名字过滤：

```sh
bun test test/user.test.ts -t "登录"
```
```
