### direct-zh-howto

```
--- step 1: user says: bun test 怎么只跑一个测试文件？
  [partner message] 用文件路径就行：

```bash
bun test test/foo.test.ts
```

也可以只写文件名的一部分，Bun 会按路径里包含这段字符的文件来筛：

```bash
bun test foo
```

如果想只跑某个测试用例，用 `-t` 按名字筛：

```bash
bun test -t "某个用例的名字"
```
```
