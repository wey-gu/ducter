## Implications for Ducter

1. **Tasks turn the plugin's automatic native session off** (`NMEM_BRIDGE_SESSION_MAILBOX=0` beside
   `NMEM_NO_MAILBOX_NOTICE=1`). A task runs as the partner's identity; the automatic session was the
   second reader research/211 found ("made 4 s after the task started"). The brief's rule and the
   home-label filter stay for plugins before the switch.
2. **Antigravity is a Bridge tool.** Its reach row stands as Claude Code's and Codex's, not in the quiet
   "can't" row. Because Mem's plugin check doesn't list Antigravity (1.8), its row says yes only from
   Mem's contact list or an exchange, else "Mem hasn't said". pi stays in the quiet row (2.3); Cursor is
   not a Ducter agent, so it has no row.
3. **Read receipts are read where Mem gives one, and recorded live before they are shown.** Ducter parses
   `read_receipt` tolerantly and only when `receipt_available` is true, so a different shape reads as
   nothing, never as a false 已读. `ducter check run mem-shapes` gains a read-only `bridge outbox` step
   (field names and counts only) and an identity-inbox step that says whether any Space still answers
   `…_unreconciled`. 已读 on 来往 waits for that run on hel.
4. Nothing in 0.10.123 retires a workaround: per-Space contexts and the 404 back-off stay for 0.10.120,
   the 5 s wait clamp stays, the stuck-mailbox line stays.
5. Still Mem's: a default personal Space, a consented enable by a trusted app, a mailbox-changed event, a
   faster first delivery, a reconcile path, an Antigravity host in `plugins inspect`. Drafted for the
   author in `research/private/bridge-ask-2026-11-25.md` (not sent).

## Summary

nmem 0.10.123 changes nothing in Bridge's verbs; it adds read receipts on outbox and inspect. The bigger
moves are in the plugins: Antigravity (0.1.4+) and Cursor (0.2.3) carry Bridge, pi has only an opt-in
start-up reminder, hosted agents get a remote-MCP skill, and Claude Code / Codex prepare a native
session automatically unless `NMEM_BRIDGE_SESSION_MAILBOX=0`. Ducter turns that off in its tasks, gives
Antigravity its own row, and reads receipts tolerantly with a live shape check owed. Long-poll, one
inbox's speed, the personal-Space default, the consented enable and the stuck state are unchanged.
