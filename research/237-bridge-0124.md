## 2. Implications for Ducter

- Receipts: read the top-level fields first and the nested shape only as an older nmem's fallback; take the
  integer `read_recipients` over status words, and never read "unread" as read (the old regex did).
  Showing 已读 / Read on 来往 is now unblocked by the contract; it is a visible change and needs shots.
- Reply: take `open`'s own `reply_args_prefix` before the entry's.
- Library: take Mem's `recommended` personal candidate first; D575's write target stays the first fact.
  A default for `folders mk` is still Mem's to add.
- Errors: keep the stderr match (D563, D590); there is no code to switch to.
- Antigravity's version from `plugins inspect`: possible now, but per workspace, and adding Antigravity to
  Mem's plugin hosts would also turn on install offers and turning the plugin off in tasks, which nobody has
  checked for agy. Left in todo.
- contact-status: not adopted while Mem's own card command answers 400.

## Summary

Of the nine asks, Mem shipped five whole (receipts' contract, Antigravity in inspect, the unreconciled
fix, pi, cross-Space reply), three in part or in another shape (recommended Space without a Library
default, contact-status still failing live, a faster inbox with the same 5 s wait), and answered the
session-kind ask by saying no inventory row is ever a session. No error codes on `--json`.
