It gives a stable origin with no domain, for $0, in about 3 steps. A stable origin is required for PWA, Web Push and passkeys. Mem Access Anywhere and dsh both wrap a CF quick or named tunnel; dsh adds 5-min pairing codes. Abacus DeepAgent has no tunnel. iOS push needs a Home Screen install on 16.4+. |
